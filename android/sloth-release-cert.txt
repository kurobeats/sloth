Sloth release signing certificate
=================================

The release keystore android/app/sloth-release.jks is committed on purpose:
Sloth is self-distributed (GitHub releases + Obtainium), not published on
Google Play, so it only needs a stable identity that every build shares.
Anyone can read it, so treat it as a public identity — it protects in-place
updates, not the app's integrity.

If this fingerprint changes, every installed copy has to be uninstalled before
it can be updated. CI fails when the keystore no longer matches it.
